# ショート動画 AI自動採点システム

完成したショート動画をAIに採点させ、「投稿OK / 保留 / 不採用」を自動判定するツールセットです。

---

## ファイル構成

```
short-judgment/
├── README.md               ← このファイル（まずここを読む）
├── analyze_short.sh        ← 動画から採点素材を抽出するスクリプト
├── ショート動画採点基準.md  ← 採点の配点・チェック項目・AIプロンプト
├── ターゲット定義.md        ← ターゲット視聴者の定義（初回は自動で設定される）
├── 動画採点の手順.md        ← 採点の全手順（詳細版）
└── .cursor/rules/
    ├── setup.mdc           ← 初期設定スタートで動くCursorルール
    └── scoring.mdc         ← 動画パスを貼ると採点が動くCursorルール
```

---

## 使い方：Cursor を使う場合（推奨）

このフォルダを Cursor で開くだけで、**チャットだけで全操作が完結**します。ファイルを開いたりコマンドを手打ちする必要はありません。

### 初回のみ：初期設定

チャットに送る：

```
初期設定スタート
```

これだけで以下が自動で進みます。

1. ffmpeg・whisper のインストール確認（不足があれば案内）
2. ターゲット視聴者（A・B・C）のヒアリング
3. `ターゲット定義.md` への自動書き込み

### 採点する

採点したい動画のファイルパスをチャットに貼るだけ。

```
/Users/自分の名前/Documents/動画.mp4
```

これだけで以下が自動で進みます。

1. 動画から素材を抽出（文字起こし・品質チェック・静止画）
2. 5軸で採点（点数・根拠・改善提案）
3. テロップ改善案を3パターン提示

複数本まとめて貼れば1本ずつ順番に処理します。

## 使い方：Cursor を使わない場合

### Step 0: 前提ソフトをインストール（初回のみ）

```bash
brew install ffmpeg
pip install -U openai-whisper
```

> Whisper はローカルで動くため **API課金は発生しません**。初回のみモデルのダウンロードが走ります（数百MB）。

### Step 1: ターゲット視聴者を設定（初回のみ）

`ターゲット定義.md` を開き、A・B・C を自分のチャンネルのターゲットに書き換える。

### Step 2: 動画から素材を抽出する

```bash
cd /path/to/short-judgment
chmod +x analyze_short.sh   # 初回のみ
./analyze_short.sh "/path/to/動画.mp4"
```

### Step 3: AIに採点させる

1. `ショート動画採点基準.md` の末尾「**8. 運用プロンプト**」をコピーする
2. ターゲット A・B・C・文字起こし・品質情報・静止画を貼って任意のAIに送信する

詳細は `動画採点の手順.md` を参照。

## 採点基準のサマリー

| 軸 | 配点 |
|---|---|
| ① 冒頭フック力 | 35点 |
| ② 感情トリガー | 20点 |
| ③ 完結性 | 15点 |
| ④ ターゲット一致度 | 15点 |
| ⑤ 映像・音声品質 | 15点 |
| **合計** | **100点** |

```
70点以上 → 投稿OK
50〜69点 → 保留（冒頭テキストを工夫すれば救える可能性あり）
49点以下 → 不採用

※ 投稿OKは次を全て満たすこと:
  合計70点以上 / 冒頭フック20点以上 / 映像音声で即0点なし
```

---

## 採点精度を上げるには

- 判定が体感とズレた動画はメモしておき、`ショート動画採点基準.md` の配点やチェック項目を調整する
- ターゲット A・B・C を具体的に書くほど、④ターゲット一致度の精度が上がる
- 文字起こし精度が足りない場合は Whisper モデルを `small` → `medium` に上げる（Cursor の場合はチャットで「medium モデルで採点して」と伝えるだけ）
