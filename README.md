# ショート動画 AI自動採点システム

完成したショート動画をAIに採点させ、「投稿OK / 保留 / 不採用」を自動判定するツールセットです。

---

## ファイル構成

```
short-judgment/
├── README.md               ← このファイル（まずここを読む）
├── analyze_short.sh        ← 動画から採点素材を抽出するスクリプト
├── ショート動画採点基準.md  ← 採点の配点・チェック項目・AIプロンプト
├── ターゲット定義.md        ← ターゲット視聴者の定義（初回は必ず書き換える）
└── 動画採点の手順.md        ← 採点の全手順（詳細版）
```

---

## クイックスタート（初めて使う人はここから）

### Step 0: 前提ソフトをインストール（初回のみ）

```bash
brew install ffmpeg
pip install -U openai-whisper
```

確認：

```bash
ffmpeg -version
whisper --help
```

> Whisper はローカルで動くため **API課金は発生しません**。初回のみモデルのダウンロードが走ります（数百MB）。

---

### Step 1: ターゲット視聴者を確認・書き換える（初回のみ）

`ターゲット定義.md` を開き、A・B・C を **自分のチャンネルのターゲット**に書き換えてください。

```
A. ターゲットの悩み     ：（例）AIを使いたいが何から始めればいいかわからない
B. ターゲットの前提知識 ：（例）ChatGPTは知っているが業務では使ったことがない
C. ターゲットの属性     ：（例）会社員・フリーランス・独立初期の20〜40代
```

> ここがズレると「④ターゲット一致度」の採点がズレます。2本目以降は確認だけでOKです。

---

### Step 2: 動画から採点素材を抽出する

```bash
cd /path/to/short-judgment
chmod +x analyze_short.sh   # 初回のみ
./analyze_short.sh "/path/to/動画.mp4"
```

実行すると `analysis/<動画名>/` に以下が出力されます。

| ファイル | 用途 |
|---|---|
| `info.txt` | 解像度・尺・音量・黒フレーム・無音区間 |
| `transcript.txt` | 音声の文字起こし |
| `frames/*.jpg` | 冒頭〜末尾の静止画（テロップ確認用） |

所要時間：動画1本あたり約30〜60秒（Whisper small モデル使用時）

---

### Step 3: AIに採点させる

1. `ショート動画採点基準.md` の末尾「**8. 運用プロンプト**」をコピーする
2. プロンプト内のターゲット A・B・C に `ターゲット定義.md` の内容を貼る
3. `transcript.txt` の内容を貼る
4. `info.txt` の内容を貼る
5. `frames/` の静止画（特に `t_0.3.jpg`・`t_end.jpg`）を添付する
6. ChatGPT / Claude / Gemini など任意のAIに送信する

---

### Step 4: 結果を読む

AIが以下を出力します。

```
【各軸】
・点数
・根拠となる発言・テロップの引用
・加減点の理由（どの項目がYes/Noか）
・改善提案（減点時のみ）

【最終判定】
合計点 / 一次判定 / ゲート通過可否 / 最終判定

【テロップ改善案】
改善案A（数字+ネガ強化）：「〇〇〇〇」 → 予測スコア: +〇点
改善案B（逆説・意外性）  ：「〇〇〇〇」 → 予測スコア: +〇点
改善案C（問いかけ形式）  ：「〇〇〇〇」 → 予測スコア: +〇点
推奨案：〇（理由）
```

## 採点基準のサマリー

| 軸 | 配点 |
|---|---|
| ① 冒頭フック力 | 35点 |
| ② 感情トリガー | 20点 |
| ③ 完結性 | 15点 |
| ④ ターゲット一致度 | 15点 |
| ⑤ 映像・音声品質 | 15点 |
| **合計** | **100点** |

### 投稿判定

```
70点以上 → 投稿OK
50〜69点 → 保留（冒頭テキストを工夫すれば救える可能性あり）
49点以下 → 不採用

※ 投稿OKは次を全て満たすこと:
  合計70点以上 / 冒頭フック20点以上 / 映像音声で即0点なし
```

詳細な配点・チェック項目・AIプロンプト全文は `ショート動画採点基準.md` を参照してください。

---

## 採点精度を上げるには

- **判定が体感とズレた動画はメモしておき**、`ショート動画採点基準.md` の配点やチェック項目を少しずつ調整する
- **ターゲット A・B・C を具体的に書く**ほど、④ターゲット一致度の精度が上がる
- **文字起こし精度が足りない場合**は Whisper モデルを `small` → `medium` に上げる

```bash
./analyze_short.sh "/path/to/動画.mp4" ./analysis medium
```
